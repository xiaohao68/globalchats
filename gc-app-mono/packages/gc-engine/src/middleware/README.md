# GC-Engine Middleware（中间件层）

## 目标

该目录用于在 `@gc/gc-engine` 内部实现一个“中间件层”，把【App-SDK】与【后台 API（@gc/api）】解耦并聚合：

- 对上：提供稳定的上报（push）与通用服务接口（查询/订阅/发送/联系人操作）
- 对内：屏蔽各平台 SDK 差异，并提供去重、重试、错误分类与可观测标识

## 边界

- 中间件不负责登录 UI 与账号注册，仅消费“已登录态”
- 中间件不实现后台业务规则与存储，只负责对接与聚合能力

## 结构（规划）

> 具体文件以实现为准。

- `backend/`：后台 API 抽象与默认适配（复用 `@gc/api`）
- `dedupe/`：短窗口去重（按 app/webview 作用域隔离）
- `errors/`：错误归一化与分类
- `observability/`：关联编号、可观测输出
- `retry/`：重试与退避策略
- `realtime/`：本地事件总线（订阅/发布）
