# WhatsApp SDK 日志使用说明

## 概述

WhatsApp SDK 现在使用统一的日志工具 `waLogger`，过滤掉无用信息，只显示核心数据上报信息。

## 日志格式

```
[时间戳] [WA-级别] [分类] 消息内容
```

示例：
```
[14:30:25] [WA-INFO] [Sync] 🚀 开始初始化同步
[14:30:26] [WA-INFO] [Login] ✅ 上报登录状态: 成功
[14:30:27] [WA-INFO] [User] ✅ 上报当前用户: 1234567890@c.us (John Doe)
```

## 日志级别

- **INFO**: 关键操作和结果（默认显示）
- **DEBUG**: 详细调试信息（需要开启调试模式）
- **ERROR**: 错误信息（始终显示）

## 开启调试模式

在浏览器控制台执行：

```javascript
// 开启调试模式（显示所有日志）
waLogger.setDebugMode(true);

// 关闭调试模式（只显示 INFO 和 ERROR）
waLogger.setDebugMode(false);
```

## 日志分类

### 1. 初始化同步（Sync）
- 🚀 开始初始化同步
- ✅ 初始化同步完成
- ❌ 初始化同步失败

### 2. 登录状态（Login）
- ✅/❌ 上报登录状态

### 3. 当前用户（User）
- ✅/❌ 上报当前用户: userId (nickname)
- ❌ 获取当前用户失败

### 4. 会话列表（Conversations）
- ✅/❌ 上报会话列表: X 个会话

### 5. 联系人列表（Contacts）
- ✅/❌ 上报联系人列表: X 个联系人

### 6. 历史消息（History）
- 📚 开始历史消息同步: X/Y 个会话（最近7天）
- 📝 会话 chatId: 原始 X → 过滤 Y → 转换 Z 条消息
- ✅/❌ 上报历史消息: chatId (X 条)
- ⏭️  跳过会话 chatId: 原因

### 7. 实时消息（Message）
- 💬 新消息: messageId
  - 发送者: senderId
  - 会话: chatId
  - 内容: "消息内容预览..."
- ✅ 上报消息: 总数 X, 接受 Y, 去重 Z

## 浏览器控制台过滤

### 只看 WhatsApp 日志
在控制台过滤器中输入：`WA-`

### 只看错误
在控制台过滤器中输入：`WA-ERROR`

### 只看特定分类
- 只看消息：`[Message]`
- 只看历史同步：`[History]`
- 只看用户信息：`[User]`

## 数据核对清单

使用日志核对以下数据：

### ✅ 登录状态
- [ ] 登录状态上报成功

### ✅ 当前用户
- [ ] 用户 ID 正确
- [ ] 用户昵称正确

### ✅ 会话列表
- [ ] 会话数量正确
- [ ] 上报成功

### ✅ 联系人列表
- [ ] 联系人数量正确
- [ ] 上报成功

### ✅ 历史消息
- [ ] 同步的会话数量正确
- [ ] 每个会话的消息数量正确
- [ ] 消息内容预览正确
- [ ] 上报成功

### ✅ 实时消息
- [ ] 新消息能够捕获
- [ ] 消息 ID 正确
- [ ] 发送者 ID 正确
- [ ] 会话 ID 正确
- [ ] 消息内容正确
- [ ] 上报成功

## 故障排查

### 问题：获取不到会话/联系人
查看日志中的调试信息：
```
[WA-DEBUG] [Conversations] _storeChat available: true/false
[WA-DEBUG] [Contacts] _storeContact available: true/false
```

### 问题：历史消息为空
查看日志：
```
[WA-INFO] [History] 📚 开始历史消息同步: 0/50 个会话（最近7天）
```
说明没有最近7天的会话，或者会话时间戳有问题。

### 问题：消息内容为空
查看实时消息日志中的内容字段，如果为空说明消息体解析有问题。
